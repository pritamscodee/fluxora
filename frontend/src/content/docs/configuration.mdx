Configuration is a single `Settings` object loaded from the environment and `.env`.
Unknown keys are ignored; everything has a default that works locally.

## Application

| Variable | Default | Notes |
| --- | --- | --- |
| `ENVIRONMENT` | `development` | Appears on webhook envelopes and traces. |
| `API_BASE_URL` | `http://localhost:8000` | Used to build absolute URLs handed to clients. Must be the externally reachable origin. |
| `CORS_ORIGINS` | `http://localhost:3000` | Comma-separated allowlist. |

## Database

| Variable | Default | Notes |
| --- | --- | --- |
| `DATABASE_URL` | SQLite file | Paste a Neon URL unmodified; see below. |
| `DB_ECHO` | `false` | Logs every statement. Noisy. |

Fluxora normalises the URL before handing it to SQLAlchemy:

- `postgresql://` and `postgres://` become `postgresql+asyncpg://`.
- `sslmode`, `channel_binding` and `options` are stripped — they are libpq parameters that
  asyncpg rejects outright.
- TLS is re-applied through the driver's own `ssl` connect argument, so stripping those
  parameters does not silently downgrade the connection.

<Callout kind="note" title="SQLite is a convenience, not a mode">
With no `DATABASE_URL` the stack runs on SQLite and self-creates its schema, which is what
lets the test suite run with no infrastructure. The job queue falls back to a
compare-and-set claim because SQLite has no `SKIP LOCKED`. Use Postgres for anything with
more than one worker.
</Callout>

## Object storage

One S3-compatible backend serves MinIO, SeaweedFS, Cloudflare R2 and AWS S3.

| Variable | Default | Notes |
| --- | --- | --- |
| `S3_ENDPOINT` | — | Empty means fall back to local disk. |
| `S3_ACCESS_KEY_ID` | — | |
| `S3_SECRET_ACCESS_KEY` | — | |
| `S3_BUCKET` | `fluxora` | Created on first use if absent. |
| `S3_REGION` | `us-east-1` | Use `auto` for R2. |
| `S3_FORCE_PATH_STYLE` | `true` | Required by MinIO and SeaweedFS. |
| `S3_PUBLIC_ENDPOINT` | — | See below. |
| `S3_CREATE_BUCKET` | `true` | Disable if the bucket is managed elsewhere. |

### `S3_PUBLIC_ENDPOINT`

A presigned URL's signature covers the hostname. If the API reaches storage at
`http://minio:9000` on a Docker network but browsers reach it at
`https://storage.example.com`, a URL signed for the first host fails the moment a browser
uses it — with an opaque 403.

Set `S3_PUBLIC_ENDPOINT` to the browser-facing origin and a second client signs
client-facing URLs against it.

### Cloudflare R2

```bash
S3_ENDPOINT=https://<account_id>.r2.cloudflarestorage.com
S3_REGION=auto
S3_ACCESS_KEY_ID=...
S3_SECRET_ACCESS_KEY=...
```

Nothing else changes.

Budget roughly 3× the largest source file per concurrent job.

### Tracing

| Variable | Default | Notes |
| --- | --- | --- |
| `LANGSMITH_TRACING` | `false` | |
| `LANGSMITH_API_KEY` | — | Tracing stays off without it, with a warning. |
| `LANGSMITH_PROJECT` | `fluxora` | |

Tracing is explicitly set to `false` when unconfigured, because a stale `LANGSMITH_TRACING`
in the environment makes every run try to reach the API and stall on network timeouts.

<Callout kind="danger" title="AGENT_REQUIRE_APPROVAL">
Turning this off lets the agent run `delete_asset`, `create_clip` and
`enable_mp4_downloads` unattended. The code logs loudly when it is disabled. It exists for
sandboxed evaluation runs, not for production.
</Callout>

## Redis and BullMQ

| Variable | Default | Notes |
| --- | --- | --- |
| `REDIS_URL` | `redis://localhost:6379/0` | |
| `AGENT_TOOL_QUEUE` | `fluxora-agent-tools` | Dead letters land in `<queue>-dlq`. |
| `AGENT_TOOL_CONCURRENCY` | `4` | |
| `AGENT_TOOL_TIMEOUT_SECONDS` | `900` | Also the BullMQ lock duration. |

Redis should run with `maxmemory-policy noeviction`. Evicting a queue key silently drops
in-flight jobs.

## Production checklist

- `JWT_SECRET` set to real entropy.
- `DATABASE_URL` pointing at pooled Postgres.
- `S3_*` set, and `S3_PUBLIC_ENDPOINT` set if the hostnames differ.
- `API_BASE_URL` set to the externally reachable origin.
- `CORS_ORIGINS` narrowed to real origins.
- `AGENT_REQUIRE_APPROVAL=true`.
- Redis with `noeviction`.
- `ENVIRONMENT=production`.
